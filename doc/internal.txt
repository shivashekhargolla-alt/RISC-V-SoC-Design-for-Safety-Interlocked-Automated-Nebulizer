================================================================================
  NebuCore SoC — INTERNAL VERIFICATION TEST PLAN & SIGNAL SPECIFICATION
  Classification: Module-to-Module Connections Inside the SoC
================================================================================

Target SoC : NebuCore Safety-Interlocked Automated Nebulizer SoC
Core       : RISC-V VeeR EL2 Processor (LSU, IFU, SB Masters)
Fabric     : AXI4 3-Master x 15-Slave Crossbar Interconnect (64-bit / 32-bit)
Scope      : Purely internal signals, module-to-module inter-IP interfaces,
             AXI bus channels, cross-peripheral safety interlocks, PIC interrupt
             lines, internal registers, and stub error responders.
Rule       : If a signal is inside the SoC connection from module to module,
             it is strictly INTERNAL.

1.1 Hardwired Cross-Peripheral Safety Interlocks (Zero-Latency Internal Wires)
--------------------------------------------------------------------------------
Signal Name        Width  Source Module      Destination Module  Description
------------------ ------ ------------------ ------------------  --------------------------------------------------
timer_done_int     1-bit  Timer IP           Watchdog Timer IP   Direct combinational wire connecting
                          (axi_timer_top)    (axi_wdt_top)       timer_done_o to wdt_trigger_i. Fires
                                                                 instantly when countdown hits 0 (dose complete).

wdt_locked_int     1-bit  Watchdog Timer IP  PWM Generator IP    Direct combinational wire connecting
                          (axi_wdt_top)      (axi_pwm_top)       wdt_locked_o to pwm_force_disable_i.

================================================================================
3. SYSTEMVERILOG ASSERTIONS (SVA) FOR INTERNAL MODULE-TO-MODULE SIGNALS
================================================================================

The following formal safety assertions monitor internal module-to-module wires
inside soc_top.sv:

// Property 1: Internal safety interlock must force PWM silence on WDT lock
property p_internal_pwm_silenced_on_wdt_lock;
    @(posedge clk)
    (u_wdt.wdt_locked_o == 1'b1) |-> (u_pwm.pwm_force_disable_i == 1'b1);
endproperty
assert property (p_internal_pwm_silenced_on_wdt_lock)
    else $fatal(1, "[INTERNAL SAFETY VIOLATION] PWM force disable not asserted when WDT locked!");

// Property 2: Internal wdt_locked latch must be irreversible without physical reset
property p_internal_wdt_lock_irreversible;
    @(posedge clk) disable iff (!rst_n)
    (u_wdt.wdt_locked_o == 1'b1) |=> (u_wdt.wdt_locked_o == 1'b1);
endproperty
assert property (p_internal_wdt_lock_irreversible)
    else $fatal(1, "[INTERNAL SAFETY VIOLATION] wdt_locked cleared without rst_n assertion!");

// Property 3: Timer Done pulse must trip WDT Lock on the next clock edge
property p_internal_timer_triggers_wdt;
    @(posedge clk) disable iff (!rst_n)
    (u_timer.timer_done_o == 1'b1) |=> (u_wdt.wdt_locked_o == 1'b1);
endproperty
assert property (p_internal_timer_triggers_wdt)
    else $error("[INTERNAL TIMING VIOLATION] WDT failed to latch lock upon timer_done_o!");

// Property 4: Unmapped AXI address access must return error response
property p_internal_unmapped_axi_error;
    @(posedge clk) disable iff (!rst_n)
    (u_interconnect.m07_axi_bvalid && u_interconnect.m07_axi_bready) |->
    (u_interconnect.m07_axi_bresp == 2'b10 || u_interconnect.m07_axi_bresp == 2'b11);
endproperty
assert property (p_internal_unmapped_axi_error)
    else $error("[INTERNAL PROTOCOL VIOLATION] Unmapped bus access did not return SLVERR/DECERR!");
